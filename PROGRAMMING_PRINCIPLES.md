## 1) Single Responsibility Principle (SRP)
- `ProjectTask` у `Program.cs` відповідає лише за стан і дані задачі.
- `ConsoleNotifier` у `Program.cs` відповідає лише за вивід повідомлень.
- `TaskService` у `Program.cs` виконує лише керування задачами (додавання, завершення, перегляд).

## 2) Dependency Inversion Principle (DIP)
- `TaskService` залежить від абстракції `INotifier`, а не від конкретного класу.
- Це дозволяє легко підмінити `ConsoleNotifier` на іншу реалізацію (наприклад, файл або Telegram-бот).

## 3) KISS
- Логіка прикладу мінімальна: додати задачу, завершити задачу, показати список.
- Код не ускладнений зайвими патернами для маленького консольного застосунку.

## 4) DRY
- Повідомлення про події відправляються через єдиний метод `Notify`, що прибирає дублювання коду виводу.
